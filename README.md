# Gellert Lera — сайт артиста

Next.js + TypeScript + Tailwind CSS + Sanity CMS.

## Быстрый старт (локально)

```bash
npm install
npm run dev
```

Откройте http://localhost:3000 — сайт работает сразу, даже без подключённой CMS: пока Sanity не настроен, используется контент-заглушка из `lib/placeholder-data.ts`, которая полностью повторяет тексты и релизы из ТЗ.

## Подключение Sanity (CMS)

1. Зарегистрируйтесь на https://www.sanity.io/manage и создайте новый проект (бесплатного плана достаточно).
2. Скопируйте `.env.example` в `.env.local` и впишите:
   - `NEXT_PUBLIC_SANITY_PROJECT_ID` — ID проекта из Sanity Manage
   - `NEXT_PUBLIC_SANITY_DATASET` — обычно `production`
3. Перезапустите `npm run dev`.
4. Откройте http://localhost:3000/studio — это админка (Sanity Studio), встроенная прямо в сайт. Залогиньтесь через тот же аккаунт, что и в Sanity Manage.
5. В Studio заполните разделы: «Настройки сайта», «Hero», «Релизы», «Обо мне», «Соцсети», «Live», «Сотрудничество». Загрузите свои фотографии — они сразу появятся на сайте.

CMS позволяет без программирования: менять фото, тексты, ссылки на соцсети, добавлять/редактировать релизы, менять названия и годы, изображения карточек и т.д. — как и было в ТЗ.

## Структура проекта

```
app/                    — страницы (Next.js App Router)
  page.tsx              — главная страница
  studio/[[...tool]]/   — встроенная админка Sanity (/studio)
components/             — визуальные компоненты (Header, Hero, MusicGrid, ...)
sanity/
  schemas/              — схемы полей для CMS
  lib/                  — клиент Sanity, GROQ-запросы, работа с изображениями
lib/
  types.ts              — TypeScript-типы контента
  placeholder-data.ts   — контент-заглушка (тексты из ТЗ)
  get-page-data.ts      — получение данных: CMS, либо заглушка
```

Каждый блок сайта — отдельный компонент, получающий данные пропсами. Ничего не зашито в код: все тексты, фото и ссылки приходят из CMS (или заглушки, пока CMS не подключена).

## Деплой

Проще всего — через [Vercel](https://vercel.com) (создатели Next.js):

1. Залейте проект в GitHub.
2. На vercel.com → «New Project» → выберите репозиторий.
3. Добавьте те же переменные окружения, что в `.env.example`, в настройках проекта Vercel.
4. Деплой запустится автоматически.
